    methodology

    the dataset is synthetic. real smith college building names are used, but the values represent an invented avoidance index rather than survey responses or institutional data.

    the campus image is a downloadable smith campus map png used here as a base layer for a schematic overlay. marker locations are approximate and meant for visual orientation, not precise navigation.

    the model estimates accidental-sighting likelihood by building and time block, then presents those estimates with the slightly overcommitted tone of a survey-based campus behavior study.
