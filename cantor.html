cantor's diagonal argument

karen colmán-martínez
smith college

suppose i told you to write down every real number between 0 and 1 in a list. every decimal expansion. all of them.

you might feel confident this is possible. after all, you can list every whole number: 1, 2, 3, 4... the list never ends, but it's a list. you have a first item, a second, a third.

cantor proved in 1891 that no such list can exist for the real numbers. not because the list would be long. because no matter what list you produce, i can always hand you a number you forgot.

here's a list. let's say someone claims it contains every real number between 0 and 1.

an allegedly complete list
look at the diagonal: the 1st digit of the 1st number, the 2nd digit of the 2nd, the 3rd of the 3rd, and so on. these are highlighted above.

now i'll build a new number. for each diagonal digit, i change it by one simple rule: if it's a 5, i write 6. anything else, i write 5. the exact rule doesn't matter, only that the digit is guaranteed to be different.

the new number
d
0.
this number differs from row 1 in position 1. from row 2 in position 2. from row \(n\) in position \(n\). it cannot be anywhere on the list.
the list was supposed to contain everything. it does not contain this number.

it follows that no complete enumeration exists. the real numbers in \((0,1)\) cannot be placed in a sequence indexed by \(\mathbb{N}\). they are uncountably infinite, strictly larger in cardinality than the natural numbers.

cantor called this distinction countable vs. uncountable infinity. \(|\mathbb{N}|\) and \(|\mathbb{R}|\) are both infinite, but \(|\mathbb{N}| < |\mathbb{R}|\).

the argument is not specific to this list. it is a general procedure: given any enumeration of real numbers, the diagonal construction produces a real number outside that enumeration. therefore no enumeration can be complete.

1891. cantor was 46. the paper is two pages. it was initially rejected.
the integers \(\mathbb{Z}\) are countably infinite: you can match them one-to-one with the natural numbers \(\mathbb{N}\).
the diagonal digit of row \(n\) is the \(n\)-th decimal place of the \(n\)-th number on the list.
more precisely: if the list existed, it would define a bijection \(\mathbb{N} \to (0,1)\). the diagonal argument shows no such bijection can exist.
\(|\mathbb{N}| < |\mathbb{R}|\). there are different sizes of infinity. this was genuinely shocking in 1891.
