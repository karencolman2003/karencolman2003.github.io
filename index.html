fixed point theorem on [0,1]
topology · real analysis

Let \(f:[0,1]\to[0,1]\) be continuous. Then \(f\) admits a fixed point, i.e., there exists \(x_1\in[0,1]\) with \(f(x_1)=x_1\).

Proof. Define \(g:[0,1]\to\mathbb{R}\) by \(g(x)=f(x)-x\). Since \(f\) and \(x\mapsto x\) are continuous, \(g\) is continuous. Evaluating at the endpoints: \(g(0)=f(0)\ge 0\) since \(f(0)\in[0,1]\), and \(g(1)=f(1)-1\le 0\) since \(f(1)\in[0,1]\). If \(g(0)=0\) or \(g(1)=0\) we are done. Otherwise \(g(0)>0\) and \(g(1)<0\), so by the Intermediate Value Theorem there exists \(c\in(0,1)\) with \(g(c)=0\), i.e., \(f(c)=c\). \(\square\)

compact + hausdorff implies homeomorphism
topology

Let \(f:X\to Y\) be a continuous injective function where \(X\) is compact, \(Y\) is Hausdorff (\(T_2\)), and \(f(X)\) is dense in \(Y\). Then \(f\) is a homeomorphism.

Proof. It suffices to show \(f\) is a closed map. Let \(C\subseteq X\) be closed. Since \(X\) is compact and \(C\) is closed, \(C\) is compact. Since \(f\) is continuous, \(f(C)\) is compact in \(Y\). Since \(Y\) is Hausdorff, every compact subset of \(Y\) is closed, so \(f(C)\) is closed in \(Y\). Hence \(f\) is a closed map.

For surjectivity: \(f(X)\) is dense in \(Y\), so \(\overline{f(X)}=Y\). But \(f(X)\) is compact and \(Y\) is Hausdorff, so \(f(X)\) is closed. Therefore \(f(X)=\overline{f(X)}=Y\). Thus \(f\) is a continuous closed bijection, hence a homeomorphism. \(\square\)

covering maps have constant fiber cardinality
topology · algebraic topology

Let \(p:X\to Y\) be a covering map where \(X\) is connected, and suppose \(|p^{-1}(y_0)|=k\) for some \(y_0\in Y\). Then \(|p^{-1}(y)|=k\) for every \(y\in Y\).

Proof. Define \(N:Y\to\mathbb{Z}\) by \(N(y)=|p^{-1}(y)|\). We show \(N\) is locally constant. For any \(y\in Y\), let \(U\) be an evenly covered neighborhood, so \(p^{-1}(U)=\bigsqcup_\alpha V_\alpha\) with each \(p|_{V_\alpha}:V_\alpha\to U\) a homeomorphism. For any \(z\in U\), the fiber \(p^{-1}(z)\) contains exactly one point in each slice \(V_\alpha\), so \(|p^{-1}(z)|\) is constant on \(U\).

Since \(N\) is locally constant, each set \(S_m=\{y\in Y\mid N(y)=m\}\) is open. The collection \(\{S_m\}\) partitions \(Y\) into disjoint open sets. Since \(Y\) is connected, exactly one \(S_m\) is nonempty, so \(N\) is constant on all of \(Y\). \(\square\)

applications of ricci curvature on graphs: community detection
graph theory · applied mathematics · may 2024 · with prof. xavier ramos-olivé

ricci curvature on a graph edge measures how "well connected" two vertices are — formalized as an optimal transport problem where the cost of moving probability mass between vertex neighborhoods determines the curvature. we explored jie gao et al.'s ricci flow algorithm, which iteratively adjusts edge weights based on curvature then performs a "surgery" to cut poorly connected edges, revealing community structure. our contribution was investigating whether assigning small weights to certain edges could prevent the algorithm from cutting connections known to be strong. we found that reducing edge weight alone is insufficient — the relative weight of neighboring edges also drives the transport cost, and this interaction needs to be accounted for in any bias-aware modification.
